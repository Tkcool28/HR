# Artifact policy

The original `hr_model_v1.1.tar.gz` extracted to approximately 252 MB. Most of that size is generated Parquet feature/data tables and serialized model artifacts.

For this repository baseline:

- Python source, tests, metadata, audit reports, manifests, and workflows belong in Git.
- Large/generated Parquet and model binaries do **not** belong in normal Git history.
- The original package is fingerprinted in `manifests/hr_model_v1.1_files.json` so every source artifact can be reconciled byte-for-byte.
- Historical 2015–2024 data/features should be regenerated by the repaired pipeline and published as GitHub Actions artifacts or a versioned release/dataset bundle when appropriate.
- The 2025 holdout remains sealed and must not be scored/evaluated during the critical historical-repair phase.

This policy is intentional: it keeps the code reviewable and the repository runnable without turning Git history into a binary data store.
